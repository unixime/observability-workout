# API update
 
## Purpose
 
Update the API definition and implementation based on user requests while ensuring consistency with the specification and proper functionality.
 
---
 
# Update Process
 
## 1. Understand the current state of API

Read api/spec.yml
 
Identify:
 
- user's request makes sense
- user's request is feasible

---

## 2. Update API Definition
 
Edit api/spec.yml to reflect the requested changes
 
---

## 3. Update API implementation
 
Review the API implementation to ensure it aligns with the updated specification.

Update or create the implementation as necessary to reflect the changes made in api/spec.yml.

---

## 4. Validate Changes

Test the updated API to ensure it behaves according to the revised specification.

Verify that all endpoints, request parameters, and response formats are consistent with api/spec.yml.

Identify and fix any discrepancies between the implementation and the specification.

Ensure that all tests pass and that the API behaves as expected after the updates.
